节点

入口节点：接收客户端流量并选路，地址填公网 host:port（仅用于展示与排障）。 中转节点：在节点间转发字节，地址必须是其他节点能直连的 IP:端口，不需要域名。

服务

服务描述一个源站。入口路径前缀由这里决定，不写死在代码里；路径白名单留空表示不限制（可交给前端反向代理处理）。
名称源站入口前缀路径白名单SSEWS启用

新增服务

路由

一个路由 = 一条从入口到源站的完整路径。跳点留空表示直连源站（用于对比线路质量）。端口由面板自动分配，也可手填。
名称服务跳点链端口权重启用

接入令牌

每个节点一个令牌，Agent 用它拉取配置并上报心跳。令牌只在创建时显示一次。
节点令牌状态创建时间

安装命令

在节点机器上以 root 执行。中转节点不需要域名和证书。
选择上方节点并生成令牌后显示

调度策略

决定同一个服务有多条路由时如何选择线路。健康度始终优先于配置顺序：坏的主线路不会遮蔽好的备用线路。

会话黏性

同一会话首次选中的线路会被固定，只有累计失败超过阈值才切换。这样长会话不会在两条线路之间来回跳。

主动探测

定期测量每条线路的延迟与成功率，作为择优依据。

限流与日志

端口池

面板在这个范围内自动给路由分配节点间转发端口。

入口监听地址

留空表示由节点自己决定（Agent 的 -listen，默认 127.0.0.1:8080）。 入口节点应只监听本地，由你自己的反向代理终止 TLS 并转发过来。 只有想统一指定时才填写，例如 127.0.0.1:9090。

生成的 Agent 配置

这是节点会实际拉取到的内容。中转节点只看到经过自己的路由。
